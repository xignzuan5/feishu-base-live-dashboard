# 合规：能抓什么，不能抓什么

抓取前先过这张清单。任何一项不满足，就停下来告诉用户原因和替代办法。

| 检查 | 要求 | 不满足时 |
|---|---|---|
| robots.txt | 允许本爬虫访问该路径（`scrape_page.py` 自动检查；robots.txt 返回 401/403 视为禁止） | 停止。建议改用官方 API、数据下载页或联系网站授权 |
| 网站条款 | 服务条款没有明确禁止自动采集或转存 | 停止，请用户确认已获授权 |
| 第三方平台 | 不是电商、外卖、社交、招聘等平台的前台页面（`scrape_page.py` 内置域名清单，命中即停止，即使 robots.txt 放行） | 停止。建议用平台的官方开放平台或商家后台导出 |
| 公开性 | 不需要登录、不在付费墙后面、不需要绕过验证码或访问限制 | 不抓。用户自己有账号也不代抓：建议导出功能或官方 API |
| 个人信息 | 不采集可识别到个人的信息（姓名 + 联系方式、证件号、住址等） | 不抓这些列；整页都是个人信息就不抓 |
| 频率 | 同一网站请求间隔 ≥ 2 秒；有缓存先用缓存；定期更新不高于每小时一次 | 降低频率 |
| 身份 | User-Agent 写明用途与项目地址，不伪装成浏览器 | — |
| 署名与许可 | 记录来源链接；数据有许可证（如维基百科 CC BY-SA）时在多维表格说明里注明 | — |

`--ignore-robots` 只在用户明确表示「网站是我们自己的」或「已获得书面授权」时使用，并在交付说明里写明。

## 推荐的替代数据源

很多数据有更正规的获取方式，抓之前先问一句：

- 政府统计数据：国家统计局、地方统计局的数据下载 / 开放平台
- 企业自己的系统：优先用系统的导出、开放 API 或飞书的集成，而不是抓网页
- 第三方平台（电商、外卖、社交）：用官方开放平台；不要抓前台页面
