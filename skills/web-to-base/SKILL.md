# 网站数据 → 飞书多维表格

把网页上的公开数据（表格、列表、结构化数据）抓下来，清洗后写进多维表格，按主键去重；数据进了多维表格，就能用 `miaoda-base-live-dashboard` 做成实时看板。

## 激活后第一件事：引导

1. 一句话说明能做什么：「我可以把网页上的公开表格 / 列表抓下来存进多维表格，之后还能做成实时看板。」
2. 用任务列表展示步骤（环境里有什么用什么，例如 `TodoWrite`），每完成一步就更新，并告诉用户下一步：
   ① 确认网址和要哪些数据 → ② 合规检查 → ③ 识别页面里的数据块 → ④ 预览并确认字段 → ⑤ 写入多维表格 → ⑥（可选）定期更新 → ⑦（可选）做成看板
3. 缺信息时**用选择框问，不让用户打字**；一次问完：

| 问题 | 选项 |
|---|---|
| 数据在哪个网页？ | 用户给链接（必填，唯一需要打字的一项） |
| 存到哪里？ | 新建多维表格（推荐）/ 已有多维表格（给链接） |
| 以后要自动更新吗？ | 只抓一次 / 每天 / 每周 |
| 抓完要直接做成看板吗？ | 要（接 `miaoda-base-live-dashboard`）/ 先不用 |

## 流程

`$SKILL` 为本 skill 目录；在一个空工作目录里运行（抓取缓存写在 `.web-cache/`）。

### ① ② 确认需求与合规

```bash
python3 $SKILL/scripts/scrape_page.py --url "<网址>"
```

第一行就是合规检查结果。电商、外卖、社交、招聘等平台的前台页面会被直接拦下（即使 robots.txt 放行），引导用户改用平台的开放接口或后台导出。**robots.txt 不允许就停下**，告诉用户可以改用官方 API、数据下载页，或联系网站授权；只有用户确认网站是自己的或已获授权，才可以加 `--ignore-robots`。完整规则见 [references/compliance.md](references/compliance.md)。

### ③ 识别数据块

脚本列出页面里能抓的数据块：`t1…` 表格、`j1…` 结构化数据（schema.org）、`l1…` 重复列表，并给出行数、列名和前 3 行预览。行数最多的表格排在最前。**把这张表原样给用户看，用选择框让用户挑数据块。**

页面是前端渲染（提示「HTML 里几乎没有正文」）、要翻页、要点「加载更多」时，走浏览器路线：[references/page-types.md](references/page-types.md)。

### ④ 导出并确认字段

```bash
python3 $SKILL/scripts/scrape_page.py --url "<网址>" --pick t1 --drop-rows "合计|总计" --out rows.json
python3 $SKILL/scripts/rows_to_base.py --rows rows.json --key <主键列> --preview
```

- `--drop-rows`：去掉合计、小计这类汇总行（按第一列匹配正则）
- `--preview` 打印每列推断的类型：数字（自动去掉千分位、%、万 / 亿）、日期、链接、单选、文本。**用选择框和用户确认主键列**：主键决定去重和更新，例如地区、商品编号、链接。

### ⑤ 写入多维表格

```bash
python3 $SKILL/scripts/rows_to_base.py --rows rows.json --key <主键列> --new-base "<多维表格名>" --table <表名>
# 或写进已有的多维表格（表不存在会自动建）
python3 $SKILL/scripts/rows_to_base.py --rows rows.json --key <主键列> --base-url <链接> --table <表名>
```

自动加「来源链接」「抓取时间」两列，方便溯源。重复运行时按主键更新已有记录，只新增新出现的记录，不删除旧记录。写完把多维表格链接和「新增 x 条、更新 y 条」告诉用户。

### ⑥ 定期更新（可选）

把 ③~⑤ 的两条命令写成一个脚本，按用户选的频率定时运行。几种做法见 [references/page-types.md](references/page-types.md#定期更新)。每次都会遵守 robots.txt 和至少 2 秒的请求间隔；页面结构变了（数据块对不上、列名变了）时停下来提醒用户，不要盲写。

### ⑦ 做成看板（可选）

数据已经在多维表格里：直接切换到 `miaoda-base-live-dashboard`，把多维表格链接带过去。用户如果画了草图或有参考截图，也一并交给它。

## 交付时汇报

网址与合规检查结果、选中的数据块、主键、字段类型、多维表格链接、新增 / 更新条数、去掉了哪些行、是否设置了定期更新、下一步建议（「要不要做成看板？」）。

## 文件

| 路径 | 作用 |
|---|---|
| `scripts/scrape_page.py` | 合规检查（robots.txt、请求间隔、可识别的 User-Agent）、抓取并缓存、识别表格 / 结构化数据 / 列表、导出 rows.json |
| `scripts/rows_to_base.py` | 推断字段类型、建表、按主键新增或更新、补来源与抓取时间 |
| `scripts/larkcli.py` | lark-cli 调用封装 |
| `references/compliance.md` | 能抓什么、不能抓什么 |
| `references/page-types.md` | 前端渲染 / 翻页 / API 页面的处理，定期更新的做法 |
