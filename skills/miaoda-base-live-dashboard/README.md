# 多维表格实时看板（miaoda-base-live-dashboard）

把飞书多维表格变成妙搭上的实时数据看板：改表后约 10 秒看板跟着变；需求可以来自飞书会议、已有的多维表格仪表盘或行业模板；8 套风格、8 种排版、每个图表都能切换类型。

## 能做什么

- **会议 → 看板**：给一场需求会的链接，自动从逐字稿提炼指标、口径和受众，生成看板，每个图表都能追溯到会上的原话
- **原生仪表盘 → 妙搭看板**：一条命令把多维表格仪表盘迁移过来，迁移后逐个面板核对数字（演示中 8 个面板全部一致）
- **行业模板开箱即用**：零售连锁（5 个精排看板 + 投屏大屏）、工作管理、客户管理，带一键造演示数据
- **实时**：多维表格流式同步进应用数据库，看板 5 秒刷新，页头显示「几秒前刷新、最新记录时间」，断连会变黄提醒
- **好看且专业**：8 套风格（深烘焙、燕麦白、霓虹大屏、晴空、墨石、青瓷、深海、松针）都经过色盲与对比度校验；同一实体在所有图里同色；自带设计检查和截图自检

## 示例提示词

- 「把这个多维表格做成实时看板，给老板周会用：<多维表格链接>」
- 「我们多维表格里有个『销售仪表盘』，搬到妙搭上，要能投屏」
- 「根据昨天下午的看板需求会，出一个客户管理看板」
- 「做一个工作管理的演示看板，风格要大气一点」
- 「给门店电视做一个实时大屏，深色、科技感」

## 依赖

- 飞书 `lark-cli`（已登录，具备多维表格与妙搭应用权限；会议来源需要视频会议 / 妙记读取权限）
- 配套 skill：`lark-base`、`lark-apps`、`lark-meeting`（会议来源）、`dataviz`（配色校验）
- 本地 Git、Node 22+、Python 3.9+

## 安全说明

- 只读多维表格和会议产物；写操作仅限：新建演示多维表格、在你自己的妙搭应用里建同步任务与代码、发布（发布前会单独确认）
- 不保存、不外传任何凭证；线上链接默认只有创建者可见
- 生成的 SQL 只引用同步映射里登记过的表和列，全部参数绑定

## 3 分钟演示脚本

| 时间 | 做什么 | 讲什么 |
|---|---|---|
| 0:00 | 打开「经营总览」（深烘焙风格），旁边开着多维表格 | 数据就在多维表格里，业务同学照常录入 |
| 0:30 | 在多维表格「订单」表新增一单（或运行 `simulate_orders.py --burst 1`） | 录完不用刷新 |
| 0:40 | 看板 5 秒内营收跳动、订单流闪入这一单 | 多维表格流式同步进应用数据库，看板 5 秒刷新 |
| 1:00 | 页头切换风格：晴空 → 松针 → 霓虹大屏；点「大屏」全屏 | 8 套风格都校验过色盲和对比度，同一个品类在所有图里同色 |
| 1:30 | 打开「模板中心」→ 工作管理「项目总览」，右上角切排版：管理层简报 → 指挥中心 → 记分对比 | 行业模板开箱即用，同一组面板 8 种排版 |
| 2:00 | 打开「多维表格迁移」看板，展示迁移报告里「8/8 一致」 | 原有的多维表格仪表盘一条命令搬过来，数字逐项核对 |
| 2:30 | 展示从会议提炼的需求溯源表（每个图表对应会上谁说的哪句话；**需提前用一场真实需求会跑一遍**） | 需求会开完，看板就能出 |
