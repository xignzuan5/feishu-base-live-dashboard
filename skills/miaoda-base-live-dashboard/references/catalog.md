# 目录：风格、排版、看板模板、面板

应用里打开「模板中心」（`/templates`）可以看到全部内容并一键切换；URL 加 `?style=<风格 id>` 可直接指定风格。

## 风格（8 套）

分类色只用两套经 `dataviz` 校验的色板（浅色 / 深色各 6 色，色盲区分与正常视觉区分都达标）；浅色风格里有 3 个颜色对浅底对比度低于 3:1，所以构成类图表一律带直接标注。

| id | 名称 | 调性 | 适合 | 标志性元素 |
|---|---|---|---|---|
| `espresso` | 深烘焙 | 科技 | 门店 / 运营值守、夜间看盘 | 暖调深底、奶油色强调、标题前小圆点 |
| `oat` | 燕麦白 | 商务 | 零售 / 餐饮品牌经营周报 | 暖白纸感、面板顶部细色条 |
| `neon` | 霓虹大屏 | 科技 | 展厅、活动现场、指挥中心 | 面板四角高光、标题发光竖条、数据线发光 |
| `sky` | 晴空 | 商务 | 销售复盘、项目周会、对上汇报 | 冷白底、蓝色强调、无装饰 |
| `graphite` | 墨石 | 克制 | 财务 / 运维监控、高密度 | 中性深灰、唯一青色强调、零阴影 |
| `celadon` | 青瓷 | 人文 | 人力盘点、品牌与内容报告 | 衬线标题与数字、灰绿纸面 |
| `abyss` | 深海 | 克制 | 会议室电视、晨会投屏 | 深青底、面板顶部青线、无发光 |
| `pine` | 松针 | 人文 | 高管驾驶舱、经营分析会 | 墨绿底、珊瑚色强调、标题前方块 |

新增风格：在 `theme/styles.ts` 加元信息与图表配色、在 `theme/dashboard.css` 加 `html[data-dash-style='<id>']` 变量块，用 `dataviz` 的 `validate_palette.js` 在该风格面板底色上校验分类色。

## 排版（8 种）

作用于配置驱动看板；每个看板右上角可切换，模板中心可设全局默认。

| id | 名称 | 结构 | 适合 |
|---|---|---|---|
| `original` | 原始布局 | 按需求说明 / 原仪表盘的 12 栅格坐标 | 迁移后保持原样 |
| `executive` | 管理层简报 | 指标带 → 横贯主图 → 两列明细 | 周会汇报 |
| `command` | 指挥中心 | 左指标、中主图、右排行三栏 | 值守、投屏 |
| `grid` | 分析工作台 | 指标带 + 三列等宽卡片 | 分析排查 |
| `workbench` | 个人工作台 | 指标在上，主列表占 8 栏，右侧提醒 | 个人 / 小组每日查看 |
| `scorecard` | 记分对比 | 三张大指标卡 + 横贯记分表 + 一排小图 | 排名、达成对比 |
| `magazine` | 杂志式 | 大图配说明，长短交错 | 对外展示、讲故事 |
| `focus` | 单列聚焦 | 居中单列长页 | 手机查看、导出长图 |

## 面板与图表类型

| 面板 | 数据形状 | 可切换图表 | 用于 |
|---|---|---|---|
| 指标卡 KpiTile | KpiItem | — | 单个关键数字 + 环比 / 参照 |
| 趋势 TrendPanel | TrendData | 折线、面积、柱状 | 时间变化；对比周期用虚线 |
| 构成 / 排行 CategoryPanel | CategoryData | 条形、柱状、矩形树图、环形、占比条 | 谁高谁低、部分与整体 |
| 多系列 StackedPanel | StackedData | 堆叠、分组、百分比 | 两个维度交叉 |
| 热力 HeatmapPanel | HeatmapData | — | 星期 × 小时等网格 |
| 散点 ScatterPanel | ScatterData | — | 两个指标的关系（气泡 = 第三个指标） |
| 进度 MeterPanel | MeterData | 圆环、进度条 | 对目标的达成 |
| 订单流 LiveFeedPanel | FeedItem[] | — | 实时滚动的最新记录，新记录闪入 |
| 明细表 TablePanel | TableData | — | 排行榜、活动效果；可排序，带进度条与状态图标 |
| 排行列表 RankListPanel | CategoryData | — | 大屏上的 Top N |
| 文本 | Markdown | — | 口径说明 |

图表规范：单一指标用风格的单色；多系列按实体固定配色（`theme/entities.ts`，颜色跟着实体走）；分类超过 6 个折叠为「其他」；不做双 Y 轴；状态色只表示状态，并配图标和文字。
