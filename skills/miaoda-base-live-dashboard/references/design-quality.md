# 设计质量：大气、专业、不像 AI 生成

「去 AI 味」不靠一段长文案让模型自觉，而靠 **定调 → 线框确认 → 机检 → 截图盲评** 四道关。每一关都有对应的 skill 或脚本。

## 四道关

| 关 | 做什么 | 用什么 |
|---|---|---|
| 1. 定调 | 先定「设计调性」（克制 / 商务 / 人文 / 科技），由它推出风格与排版；不要先挑颜色 | 本文「调性 → 风格 / 排版」；`frontend-design` skill 的做法：从业务本身（行业、使用场合、受众）找视觉依据 |
| 2. 线框确认 | 每个看板画 ASCII 线框图给用户看，确认信息层级再生成 | `requirements-from-meeting.md` 第 4 步 |
| 3. 机检 | 需求说明过一遍设计规则；新增 / 修改配色跑色盲与对比度校验 | `scripts/lint_spec.py`；`dataviz` skill 的 `validate_palette.js` |
| 4. 截图盲评 | 每个看板 × 选定风格截图，自己先看一遍；两套候选风格或排版拿不准时做 A/B 盲评 | `agent-browser` 截图；`ux-aesthetic-review` skill（盲评，不告诉评审哪张是哪套） |

## 调性 → 风格 / 排版

| 调性 | 特征 | 风格 | 排版 |
|---|---|---|---|
| 克制 restrained | 灰阶为主、只留一个强调色、无阴影、密度高 | 墨石、深海 | 指挥中心、分析工作台 |
| 商务 corporate | 规整、浅底、蓝或品牌色强调、留白充足 | 晴空、燕麦白 | 管理层简报、记分对比、个人工作台 |
| 人文 editorial | 衬线标题、大字号数字、长短交错 | 青瓷、松针 | 杂志式、管理层简报 |
| 科技 technical | 深底、发光或高饱和强调、远距离可读 | 霓虹大屏、深烘焙 | 指挥中心、实时大屏 |

每种风格的标志性元素最多两处（如霓虹的四角高光 + 标题发光竖条、青瓷的衬线标题与数字），并且在全站一致地重复。

## 不要做（常见的 AI 生成特征）

文案
- 「A · B · C」中间点串联的说明文字；「词 — 片段」式标签；每个标题上方都加小号说明标签
- 只把标题里的一个词加粗或变色
- 数字后面跟一堆无意义的「↗ 持续增长」「🚀」；看板里不用 emoji

视觉
- 所有卡片同一个圆角、同一种灰色阴影、同样大小（指标卡、主图、明细应有层级差）
- 装饰性渐变铺底、玻璃拟态、无意义的发光（大屏风格除外，且只用在边框、标题等标志性元素上）
- 米白底 + 衬线大标题 + 赤陶色强调；纯黑底 + 单个荧光绿强调——除非业务本身就是这个调性
- 每个区块进场都做渐入上滑；hover 时每张卡都浮起

数据
- 光秃秃一个数字，没有对比目标、上期或同期（指标卡必须有参照）
- 双 Y 轴；饼 / 环形图超过 5 个扇区；为了花样换图型
- 同一个实体在不同图里颜色不同；用颜色排名（颜色要跟着实体走）
- 红绿表达涨跌又同时表达状态；状态色不配图标和文字

## 要做（检查清单）

1. **一屏讲完**：管理层看板和大屏不出滚动条；最重要的放左上，按 Z 型阅读
2. **每页 4~9 个指标**，每个都能支撑一个决策；比率类写清分子分母（subtitle）
3. **指标卡有参照**：环比 / 同期 / 目标，至少一个；越少越好的指标设 `good_when: down`
4. **数字**：3~4 位有效数字，大数用「万 / 亿」，千分位，空值「—」，24 小时制，日期 `MM-DD`；数字用等宽数字（tabular-nums）
5. **时间口径统一**：同一看板的面板用同一个时间范围；不同日期字段写在 subtitle
6. **克制用色**：单一指标用一个颜色，多系列按实体固定配色（`theme/entities.ts`），强调色只给重点和异常
7. **图表外观**：网格线只沿数值轴且很浅；标题已说明单位就不写轴标题；数据标签只给条形 / 柱状 / 树图这类需要读数的图
8. **栅格**：12 栅格、统一 12px 间距、面板只用大中小三档宽度；同一行面板等高；长列表定高后内部滚动
9. **新鲜度**：页头显示「x 秒前刷新，最新记录 hh:mm:ss」；超过 30 秒没刷新显示黄色「连接异常」
10. **无障碍**：图表带 `aria-label` 摘要；图标按钮带 `aria-label`；尊重「减少动态效果」系统设置

## 截图自检怎么做

```bash
# 每个看板 × 选定风格各截一张全页图，逐张看：标题是否说清、数字是否对齐、图例与配色是否一致、空状态、时区
agent-browser set viewport 1600 1000
agent-browser open "http://localhost:<port>/app/<app_id>/spec/<board>?style=<style>"
agent-browser screenshot --full shots/<board>-<style>.png
# 大屏按 1920×1080 截一张，确认一屏放下
```

两套方案拿不准时（比如「晴空 + 管理层简报」vs「松针 + 杂志式」），把两张截图交给 `ux-aesthetic-review` 做盲评，按它的结论选，并把理由写进交付说明。
